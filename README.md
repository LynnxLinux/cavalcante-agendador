# Cavalcante Conversion

Crie uma landing page profissional, moderna e altamente focada em conversão para um salão de beleza/cabeleireiro local.

OBJETIVO

O principal objetivo da página é transformar visitantes vindos do Instagram e Google em clientes, levando-os a entrar em contato pelo WhatsApp para agendar um horário.

A página deve transmitir:

* profissionalismo

* confiança

* qualidade

* experiência

* estética premium

* facilidade para agendar

Não quero uma aparência genérica de template. O design deve parecer feito especificamente para este salão.

ESTRUTURA DA PÁGINA

1. HERO

Criar uma primeira seção visualmente impactante.

Incluir:

* título forte orientado ao benefício

* subtítulo curto

* CTA principal "Agendar pelo WhatsApp"

* CTA secundário para conhecer os serviços

* imagem de alta qualidade relacionada ao salão/cabelo

* indicação visual de localização ou atendimento local

O CTA principal deve aparecer claramente acima da dobra no celular.

Evite textos genéricos como "Bem-vindo ao nosso salão".

Crie uma headline que comunique transformação, beleza e confiança.

2. PROVA SOCIAL

Criar uma seção com avaliações/depoimentos reais fornecidos pelo negócio.

Mostrar:

* nome do cliente

* avaliação

* estrelas

* comentário

Não invente avaliações. Caso os depoimentos não sejam fornecidos, deixar conteúdo claramente marcado para substituição.

3. SERVIÇOS

Criar cards elegantes para os principais serviços.

Cada card deve apresentar:

* nome

* breve descrição

* preço, caso fornecido

* CTA para agendar

Não inventar preços.

4. GALERIA

Criar uma galeria visual com fotos do salão, cortes, penteados ou resultados.

Usar layout moderno e responsivo.

As imagens devem valorizar o trabalho realizado pelo profissional.

5. DIFERENCIAIS

Criar uma seção mostrando por que o cliente deveria escolher este salão.

Utilizar ícones discretos e textos curtos.

6. SOBRE O SALÃO

Criar uma seção apresentando a história/profissional responsável pelo salão.

Usar uma imagem do profissional caso fornecida.

O texto deve transmitir personalidade e confiança, sem parecer corporativo demais.

7. INSTAGRAM

Criar uma seção visual convidando o visitante a conhecer o Instagram do salão.

CTA: "Conheça nosso Instagram"

Link: [INSTAGRAM]

8. LOCALIZAÇÃO

Criar seção com:

* endereço

* horário de funcionamento

* mapa/Google Maps

* botão para abrir rota

9. CTA FINAL

Criar uma seção forte de conversão próxima ao final da página.

Exemplo de intenção:

"Pronta para transformar seu visual?"

Adicionar botão grande:

"Agendar meu horário"

O botão deve abrir uma conversa no WhatsApp.

10. FOOTER

Incluir:

* nome do salão

* cidade

* WhatsApp

* Instagram

* endereço

* links importantes

WHATSAPP

Todos os principais CTAs devem direcionar para:

https://wa.me/[NUMERO]

Adicionar uma mensagem pré-preenchida, por exemplo:

"Olá! Vi o site de vocês e gostaria de agendar um horário."

DESIGN

Criar um design premium, elegante e contemporâneo.

Paleta:

* [COR PRINCIPAL]

* [COR SECUNDÁRIA]

* branco/off-white

* tons neutros

Tipografia:

* uma fonte elegante para títulos

* uma fonte altamente legível para textos

Usar bastante espaço em branco.

Evitar:

* excesso de gradientes

* excesso de animações

* aparência de template

* excesso de elementos decorativos

* textos longos

* cards desnecessários

MOBILE FIRST

A maioria dos visitantes provavelmente virá do Instagram pelo celular.

Portanto:

* priorizar mobile

* botões grandes

* textos legíveis

* carregamento rápido

* navegação simples

* CTA de WhatsApp sempre fácil de encontrar

Adicionar um botão flutuante de WhatsApp no mobile.

SEO LOCAL

O site deve ser preparado para SEO local.

Utilizar naturalmente:

* nome do salão

* cidade

* bairro

* serviços

* palavras relacionadas a cabeleireiro/salão de beleza

Adicionar:

* title

* meta description

* headings semânticos

* informações de localização

Não fazer keyword stuffing.

CONVERSÃO

A página inteira deve conduzir o visitante para uma ação principal:

AGENDAR PELO WHATSAPP.

Distribuir CTAs ao longo da página sem deixar a experiência agressiva.

Criar sensação de confiança antes de pedir o agendamento.

IMPORTANTE

Não invente informações sobre o estabelecimento.

Quando alguma informação não for fornecida, use placeholders claramente identificáveis para que eu possa substituir depois.

O resultado final deve parecer um site real, premium e pronto para apresentar ao proprietário do salão
